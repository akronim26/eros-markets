# A ↔ B interface reconciliation (integration/risk)

Spec v1.1 / economic baseline v1.0. Each row: what B assumed (docs/merge/B-assumptions.md),
what A built, the resolution, and the commit type. "Bridge" = `contracts/src/engine/RiskAccountingBridge.sol`
(integration-owned composition: implements B's `IAccountingPort` on A's real functions and
answers A's `_riskContext` / `_riskAccept` with B). No balance is set by the bridge; every
cash/position/fee/reserve movement happens inside an A function.

Updated by Person A's integration review on 2026-10-02. Rows marked "A review working tree"
describe the reviewed changes, now committed through `ec14175`; G0-G7 technical checks pass.
Those labels are not retrospective approval of the original integration. B delta review is
still required. The gate record remains
`docs/spec/gate_status.json`.
