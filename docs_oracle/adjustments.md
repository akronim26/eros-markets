# Plan adjustments

Every place where `eros-oracle-implementation-plan.md` (the plan) contradicts itself, contradicts the
repository, or leaves something unspecified that a task needs. Each entry gives the resolution the
task breakdown uses. None of them changes a rule, a number, a type or an interface of the plan. To
change a resolution, edit the entry and every task that references it, then run
`python3 docs_oracle/check_tasks.py`.
